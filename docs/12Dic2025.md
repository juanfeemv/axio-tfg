RESUMEN TÉCNICO DEL PROYECTO AXIO (Hito: Fin Sprint 5)

Fecha: Diciembre 2025
Estado: Funcionalidad Core + Colaboración completada.

1. ARQUITECTURA DEL SISTEMA

El proyecto sigue una arquitectura Full-Stack Isomórfica (JavaScript/TypeScript) desplegada mediante contenedores.

Backend (Servidor)

Tecnología: Node.js con Express y TypeScript.

API: RESTful para operaciones CRUD y WebSockets (Socket.io) para tiempo real.

Seguridad: Autenticación mediante JWT (JSON Web Tokens) y Bcrypt para hashing de contraseñas.

IA Integrada: Google Gemini 2.5 Flash para análisis semántico multimodal (visión y texto).

Scraping: Puppeteer para la navegación headless y captura de webs en vivo.

Almacenamiento: Sistema de archivos local (/uploads) gestionado con Multer para imágenes y código fuente.

Frontend (Cliente)

Tecnología: React 18 con Vite y TypeScript.

Estilos: Tailwind CSS con diseño responsivo y tema oscuro/claro persistente.

Estado: Context API (AuthContext, SocketContext, ThemeContext) para gestión global.

Navegación: React Router v6 con rutas protegidas y persistencia de estado de navegación.

UX/UI: Efectos de Glassmorphism, animaciones y feedback optimista en interacciones.

Base de Datos

Motor: MongoDB (NoSQL).

Modelos Principales:

User: Datos de perfil y credenciales.

Project: Metadatos del proyecto, tipo (URL/File/Code), estadísticas de votos y likes.

Audit: Resultados del análisis de IA (puntuación, array de problemas).

Pin: Coordenadas y contenido de los comentarios colaborativos.

2. FUNCIONALIDADES IMPLEMENTADAS (Por Sprint)

✅ Sprint 1: Núcleo del Backend

Servidor Express configurado con TypeScript.

Conexión robusta a MongoDB.

Sistema de Registro y Login seguro.

✅ Sprint 2: El Cerebro (IA y Archivos)

Análisis Multimodal: Capacidad para procesar Imágenes, PDFs, Código Fuente y URLs.

Pipeline de IA: Integración con Gemini para detectar errores de accesibilidad y sugerir correcciones.

Persistencia: Guardado automático de auditorías vinculadas a usuarios.

✅ Sprint 3: Frontend MVP

Dashboard Interactivo: Panel principal con interruptor para modo "Análisis IA" o "Solo Subir".

Gestión de Proyectos: Vista "Mis Proyectos" con filtrado por tipo, búsqueda y eliminación.

Perfil de Usuario: Configuración de cuenta, cambio de contraseña y personalización de tema.

✅ Sprint 4: Motor de Empatía

Simulación Sensorial: Filtros SVG en tiempo real para simular daltonismo (protanopía, deuteranopía, tritanopía), visión borrosa y acromatopsia.

Visor Inteligente: Adaptación de la interfaz según el contenido:

Web/Imagen: Lienzo interactivo con filtros.

PDF: Visor embebido.

Código: Editor de texto con resaltado de sintaxis.

✅ Sprint 5: Colaboración y Comunidad

Tiempo Real (WebSockets): Sincronización instantánea de acciones entre usuarios conectados al mismo proyecto.

Sistema de Pines: Colocación de marcadores visuales sobre imágenes/diseños con coordenadas relativas (responsive).

Chat Integrado: Panel lateral de discusión para comentarios generales.

Feed de Comunidad: Explorador de proyectos públicos con:

Sistema de Likes con actualización optimista.

Sistema de Votación (Estrellas) con cálculo de media en backend.

Filtros avanzados (Recientes, Populares, Mejor Puntuados).
